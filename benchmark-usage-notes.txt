Benchmark usage notes

1) Start baseline Kvrocks only:
   docker compose up -d kvrocks

2) Start Kvrocks + OTEL stack:
   docker compose --profile otel-stack up -d kvrocks otel-collector prometheus grafana

   Endpoints:
   - OTLP gRPC ingest: localhost:4317
   - OTLP HTTP ingest: localhost:4318
   - Prometheus query: http://localhost:9090
   - Grafana UI: http://localhost:3300

3) Start optional runner container for in-compose execution:
   docker compose --profile runner up -d kvrocks runner

4) Run small-tier approaches from host:
   rtk go run ./cmd/approach-a -tier small -kvrocks-addr 127.0.0.1:6666
   rtk go run ./cmd/approach-b -tier small -kvrocks-addr 127.0.0.1:6666
   rtk go run ./cmd/approach-c -tier small -kvrocks-addr 127.0.0.1:6666
   rtk go run ./cmd/approach-d -tier small -kvrocks-addr 127.0.0.1:6666

5) Run one-command required matrix (A/B/C/D across small+medium):
   rtk go run ./cmd/bench -kvrocks-addr 127.0.0.1:6666 -artifacts-dir artifacts

6) OTEL toggle per run (local metrics always emitted):
   add -otel-enabled=true -otel-endpoint=<label>

7) OTEL stack smoke check:
   ./tests/otel_stack_smoke.sh

7) Stop environment:
   docker compose down
